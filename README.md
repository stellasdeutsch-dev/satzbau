# SATZBAU — порядок слов в немецком

Разбор того, почему немецкий глагол вечно стоит на втором месте, куда улетает
приставка и что за рамка зажимает половину предложения.

## Что внутри

- **Конструктор предложения** — двигаешь любой член предложения на первое место
  и видишь, что глагол не сдвигается, а подлежащее уходит вправо (инверсия)
- **Satzklammer** — рамочная конструкция с дугой между двумя глагольными частями,
  четыре типа: Perfekt, модальный, отделяемый глагол, Futur
- **Отделяемая приставка** — по кнопке приставка отрывается от инфинитива
  и по дуге улетает в конец предложения
- **TeKaMoLo** — обстоятельства перемешиваются и собираются обратно
  в порядок «когда → почему → как → куда»
- **Nebensatz** — выбираешь союз, глагол уезжает в самый хвост
- **Озвучка** — тап по любому немецкому слову произносит его через Web Speech API,
  голос и скорость выбираются и хранятся в `localStorage`
- Mobile-first, `prefers-reduced-motion`, без внешних зависимостей кроме Google Fonts

## Разработка

```bash
python3 -m http.server 4189
```

`?nofx` в конце адреса отключает анимации появления — удобно для проверки вёрстки.
